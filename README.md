# BOYX Store

باش تشوف الستور مزيان، ما تفتحش `index.html` مباشرة.

الطريقة السهلة:

1. دوبل كليك على `start-store.bat`
2. حل هاد الرابط فالمتصفح:
   `http://127.0.0.1:5173/`

ولا من terminal:

```bash
npm run dev
```

ومن بعد دخل لـ:

```text
http://127.0.0.1:5173/
```

إلا بغيتي نسخة جاهزة للرفع:

```bash
npm run build
```

غادي تلقاها فـ `dist/`.
